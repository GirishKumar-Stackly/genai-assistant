# Prompt Version Comparison

## Objective

Compare two prompt versions using the same fixed prompt test dataset.

The goal is to determine whether the improved prompt provides more reliable structured output and better validation results.

---

## Prompt Versions

### V1 - Basic Prompt

The V1 prompts provide the task instructions but do not strongly enforce JSON-only output.

Example:

- Summarize the document.
- Extract requested fields.
- Classify the document.

V1 may allow the model to return Markdown, explanations, or other non-JSON formatting.

---

### V2 - Structured Output Prompt

The V2 prompts add explicit structured-output instructions.

Key changes:

1. Return ONLY valid JSON.
2. Do not use Markdown.
3. Do not use JSON code fences.
4. Define the exact required JSON fields.
5. Define allowed classification values.
6. Define how missing extraction values should be represented.
7. Separate instructions from document input using delimiters.

---

## Meaningful Prompt Change

The main meaningful change was adding strict JSON output instructions to V2.

### V1

The model was simply asked to perform the task.

### V2

The model was explicitly instructed to return only valid JSON matching the required structure.

This change was made to improve output-format reliability and reduce JSON validation failures.

---

## Evaluation Dataset

Both versions will be evaluated using the same fixed dataset:

- Total cases: 10
- Summary cases: 5
- Extraction cases: 3
- Classification cases: 2

Using the same cases ensures that the comparison is fair.

---
